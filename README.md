# Amirian Curse 3D

A fan-made 3D recreation of the 2D game Amirian Curse. It runs in your web browser.

## How to open the game

1. Download this project (green **Code** button, then **Download ZIP**) and unzip it.
2. Open a terminal in the unzipped folder and run:

   ```
   python3 -m http.server 8123
   ```

   On Windows, use `python -m http.server 8123`.
3. Open this address in Chrome or Safari:

   ```
   http://127.0.0.1:8123
   ```

Leave the terminal window open while you play. To stop, close the browser tab and press Ctrl+C in the terminal.

## Good to know

- You need Python 3 (already on a Mac; on Windows get it from python.org) and an internet connection.
- Double-clicking `index.html` does not work. The game has to be opened through the address above.
- The controls are listed at the bottom of the screen once the game starts.
- Your progress is saved in the browser you play in.
